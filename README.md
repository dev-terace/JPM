## 메인 기술

- **Gradle Plugin**
  - 프로젝트 빌드 및 의존성 관리

- **ArchUnit**
  - 아키텍처 규칙 검증
  - 패키지 간 의존성 및 계층 구조 검사

- **MyBatis**
  - SQL 기반 데이터 접근 및 DB 연동

- **AutoService Annotation**
  - Annotation Processor 기반 자동 구현체 등록
  - 서비스 구현체 탐색 및 등록 과정 자동화
